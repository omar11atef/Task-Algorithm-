# Task-Algorithm-
# 📌 Sort Colors Visualizer (Dutch National Flag Algorithm)

## 📂 Project Structure

- **`index.html`** – Frontend user interface. Includes the interactive visualizer, animations, and Tailwind CSS styling.  
- **`app.py`** – Flask server handling routing and API requests.  
- **`color_sorter.py`** – Backend logic class that validates inputs and processes sorting on the server side.  

---

## ✨ Key Features

- **Interactive Visualizer:** Watch the sorting process step-by-step with **Low**, **Mid**, and **High** pointers.  
- **Playback Controls:** Play, pause, reset, and step through the algorithm at your own speed.  
- **Dual Verification:** Frontend visualizes the efficient partitioning logic, while the Python backend validates the final result via API.  
- **Custom Inputs:** Users can define the array size ($N$) and the specific sequence of colors.  
- **Modern UI:** Styled with Tailwind CSS for a clean, responsive dark/light mode aesthetic.
